# TARS — Living Face

A standalone experimental expressive robot face, separate from AKAKBURGER Member Hub.

## Current build
`index.html`: **P03-R2.6 Mobile Edition** — self-contained HTML/CSS/JS, mobile and desktop.

Features: expressions, depth/perspective eyes, independently rotating orbital rings, strong differential inertia, mood-sensitive motion, curved/multi-turn/slingshot trajectories, touch/drag/flick, dizziness and anger.

## Version policy
- **P03-R2.4** approved and locked; original source **not yet archived** in this repository.
- P03-R2.5 experimental; original source not yet archived.
- P03-R2.6 current adaptation, pending testing and approval.
Do not misrepresent a reconstructed version as the original baseline.

## GitHub Pages setup
After merging: Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

Then the expected URL is https://aryomsd.github.io/tars-living-face/ (only after the Pages build succeeds).

## Interaction
Drag or flick TARS's face; rapidly shake to trigger dizziness/anger. The buttons trigger expressions and speech. Sound is opt-in. Mobile uses touch; desktop uses pointer.
